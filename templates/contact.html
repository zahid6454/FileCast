Email
support@filecast.org — general questions, feedback, bug reports, or anything else

Reporting a problem

If you're reporting a problem with a specific tool, include the tool name and a description of what went wrong. Screenshots help, but never send the file you were converting — we don't need it and don't want it.

For bug reports, please include your browser name and version, the tool you were using, and a description of what happened versus what you expected.

Response time

This is a small project, not a large company. Expect a response within a few business days. Bug reports that affect many users are prioritized.
