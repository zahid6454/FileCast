## Frequently Asked Questions

### Is it safe to reorder my PDF here?

Yes. This tool processes your file entirely in your browser. Your PDF is never uploaded to any server — everything happens locally on your device.

### How do I specify the new page order?

List every page number, separated by commas, in the order you want them to appear — for example, "3,1,2,4" for a 4-page PDF puts the current page 3 first, then page 1, then page 2, then page 4.

### Do I have to list every page?

Yes. The new order needs to include every page in the document exactly once — this tool reorders pages, it doesn't drop any. If you also want to remove some pages, use [PDF Remove Pages](/convert/pdf-remove-pages) or [PDF Extract Pages](/convert/pdf-extract-pages) instead.

### What happens if I list a page twice or leave one out?

The tool tells you the list doesn't match the document — either a page number is missing or repeated — and doesn't produce a file, so you can correct it and try again.

### Does reordering affect the content of individual pages?

No. Reordering only changes the sequence pages appear in — the content, formatting, and quality of each page stays exactly as it was.
