## Reordering Pages vs Extracting or Rotating

Fixing a PDF's page structure can mean a few different things depending on what's actually wrong with it.

<div class="table-scroll" markdown="1">

| Consideration | PDF Organize | PDF Extract Pages | PDF Rotate |
|---|---|---|---|
| Fixes | Wrong page order | Need only some pages, not all | Pages facing the wrong direction |
| Page count in the output | Same as the original | Fewer — only the pages you list | Same as the original |
| What you specify | The full new order for every page | Which pages to keep, and in what order | Which rotation angle to apply |
| Typical use | "These pages are all here, just out of order" | "I only need some of these pages" | "These pages are sideways" |

</div>
