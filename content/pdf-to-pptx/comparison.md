## PDF vs PPTX — When to Convert

| Feature | PDF | PPTX |
|---|---|---|
| Editing | View-only by design | Add, remove, reorder slides |
| Presenting | Awkward — no slide transitions | Built for presenter view and transitions |
| Text editing | None | Only on newly added/typed slides* |
| Layout consistency | Identical on all devices | Depends on the app rendering it |
| Universal viewing | Any PDF viewer | Needs PowerPoint or compatible app |

\* Slides converted from a PDF page are an image of that page — see the FAQ below.

### Keep PDF When

Stay with PDF when you're distributing a finished document for reading — a report, a handout, an archived record where layout consistency matters more than reorderability.

### Convert to PPTX When

Switch to PPTX when you need to present the content, reorder pages into a different sequence, or drop a few pages from an existing PDF into a larger deck you're building.
