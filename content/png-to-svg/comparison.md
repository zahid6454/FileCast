## PNG vs SVG — When to Use Each

| Feature | PNG | SVG |
|---|---|---|
| Made of | A grid of pixels | Vector shapes (math, not pixels) |
| Scaling | Blurs/pixelates when enlarged | Stays sharp at any size |
| Best for | Photos, screenshots, complex art | Logos, icons, flat illustrations |
| File size at large sizes | Grows with resolution | Stays small regardless of size |
| Editable in a vector app | No | Yes — shapes, colors, and paths |
| Gradients and photo detail | Full support | Limited — approximated as shapes |

### Keep PNG When

Stay with PNG for photos, screenshots, and any image with fine gradients, textures, or thousands of subtle colors — the pixel grid is exactly what makes those look right.

### Convert to SVG When

Switch to SVG when you have a logo, icon, or flat-color graphic that only exists as a PNG and you need it to scale cleanly — on a website, in print at any size, or editable shape-by-shape in a vector editor.
