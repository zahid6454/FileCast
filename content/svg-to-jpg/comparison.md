## SVG vs JPG — When to Use Each

Both formats have strengths. The right choice depends on what you're doing with the image.

<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-minimize"></use></svg>File size</span></td><td data-label="SVG">Usually very small for simple graphics</td><td data-label="JPG">Larger, especially at high resolutions</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg>Transparency</span></td><td data-label="SVG">Supported</td><td data-label="JPG">Not supported</td></tr>

    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-code"></use></svg></span>
      <h3>Keep SVG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need the image to look sharp at different sizes</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You plan to edit colors, shapes, or other elements later</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're using it on a website where scalability matters</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want the smallest possible file size for simple graphics</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to animate the image</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to JPG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The platform you're using doesn't accept SVG files</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to upload an image to social media or a profile picture</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're adding the image to a Word document, PowerPoint, or email</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want to share the image with someone who may not have software that opens SVGs</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need a specific pixel size for printing</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Transparency doesn't matter and you want the smallest possible file for a photo-style image</li>
    </ul>
