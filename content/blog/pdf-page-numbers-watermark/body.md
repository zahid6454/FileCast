## Two Stamps, One Page

Page numbers and watermarks are both "stamp something onto every page" operations, and it's common to need both on the same document — a draft report with "DRAFT" diagonally across each page and a page number in the corner. Run them in the wrong order, though, and the result can look worse than either one alone.

## Why Order Changes the Result

Neither tool edits the other's addition or removes anything — each one draws new content onto whatever's already on the page. The only thing order actually changes is *which stamp sits visually on top* when they happen to overlap. A page number is small and usually tucked in a corner; a watermark, by contrast, is typically large text set diagonally across most of the page — at a 45° angle centered on the page, it can pass close to corner and bottom-center positions on a lot of standard page sizes.

If a dense, high-opacity watermark gets added *after* the page number, it can visually cross right over the number, making it harder to read even though the number is technically still there underneath. Add the watermark first and the page number afterward, and the number always renders cleanly on top, fully legible regardless of what the watermark looks like underneath it.

## The Practical Rule

Add the watermark first, then the page numbers — treat the watermark as the background layer and the page number as the layer that always needs to stay readable. It also happens to match how most people think about the two anyway: the watermark is a property of the whole document ("this is a draft"), while the page number is a per-page reference detail that a reader actually needs to be able to read at a glance.

If you've already added page numbers and then applied a watermark that's crossing over them, redoing it in the other order — or lowering the watermark's opacity and font size — clears it up without starting from the original document.
