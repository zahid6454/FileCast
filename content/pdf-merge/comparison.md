## Merging vs Keeping Separate — When to Combine

Combining PDFs into one file isn't always necessary. Sometimes keeping documents apart makes more sense. Here's how to decide.

| Consideration | Separate Files | Merged File |
|---|---|---|
| Submission requirements | Portal accepts multiple uploads | Portal accepts only one file |
| Sharing ease | Recipient can pick what to read | Recipient gets everything in one place |
| File updates | Easy to swap out one document | Must re-merge if one part changes |
| Organization | Folders keep things grouped | Single file is self-contained |
| Page count | Short, unrelated documents | Related documents that belong together |

### Keep Separate When

- Each document is updated independently and on different schedules
- Recipients only need certain files, not the full set
- The files are unrelated and just happen to live in the same folder
- You're collaborating with others who each own a specific document
- Individual files are already large and combining them would create an unwieldy document

### Merge When

- A submission portal or email only allows a single file upload
- You need to present materials in a specific order — like a proposal with appendices
- You're archiving a completed project and want one reference file
- You're sending documents to someone who shouldn't have to hunt through attachments
- You're preparing a print-ready package where page sequence matters
- You want to create a unified report from sections written by different people
