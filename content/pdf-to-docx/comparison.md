## PDF vs DOCX — When to Convert

| Feature | PDF | DOCX |
|---|---|---|
| Editing | View-only by design | Fully editable |
| Layout consistency | Identical on all devices | Varies by software and fonts |
| Text reflow | Fixed positions | Adjusts to page size |
| Tables | Visual only | Editable cells with formulas |
| Collaboration | Limited annotations | Track changes, comments |
| File size | Compact with embedded fonts | Generally smaller |
| Universal viewing | Any PDF viewer | Needs Word or compatible app |

### Keep PDF When

Stay with PDF when the document is final and shouldn't be edited — contracts for signing, published reports, archived records, or anything where layout consistency matters more than editability.

### Convert to DOCX When

Switch to DOCX when you need to make changes. Updating outdated information, extracting content for a new document, reformatting a report, or editing text that someone sent as a locked PDF — all of these are faster with a Word document than retyping from scratch.
