## ICO vs PNG — When to Use Each

<div class="table-scroll">
<table class="icon-table">

<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-file-plus"></use></svg>Multiple sizes in one file</span></td><td data-label="ICO">Yes — several sizes bundled together</td><td data-label="PNG">No — one image per file</td></tr>

<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-target"></use></svg>Best for</span></td><td data-label="ICO">Browser tab icons, Windows app icons</td><td data-label="PNG">Editing, sharing, general-purpose images</td></tr>

      <h3>Keep ICO When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're using the file as a website favicon or Windows app icon</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need the multi-size bundling a browser or OS expects</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want to edit the icon's artwork in an image editor</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to reuse the icon's image somewhere other than a favicon or app icon</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're extracting a logo from an old favicon to use as a fresh source image</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want a single, standard image file instead of a multi-size bundle</li>
    </ul>
  </div>
