## Frequently Asked Questions

### Is it safe to compress my images here?

Yes. This tool processes your images entirely in your browser. Your files are never uploaded to any server — everything happens locally on your device. No one else can see or access your images during or after compression.

### What quality setting should I use?

For most photographs, 70-80% strikes a good balance between file size and visual quality. At these levels, the difference from the original is nearly impossible to spot. If you're compressing images with fine text or detailed graphics, staying at 85% or above helps preserve sharpness. Below 50%, quality loss becomes more noticeable and is best reserved for situations where small file size matters more than appearance.

### Does compression change the image dimensions?

No. Compression only reduces file size — the width and height of your image stay exactly the same. If you need to change the dimensions, use a resizing tool instead.

### Which image formats are supported?

This tool accepts JPG, PNG, and WebP files. The compressed output maintains the same format as your original, so a JPG stays a JPG and a PNG stays a PNG.

### Can I compress multiple files at once?

This tool compresses one file at a time. Select an image, adjust the quality slider, download the result, then start again with the next file. If you have a batch of images to process, the bulk compressor tool lets you handle multiple files in one session.
