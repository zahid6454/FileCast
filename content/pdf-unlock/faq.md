## Frequently Asked Questions

### Is it safe to unlock my PDF here?

Yes. This tool processes your file entirely in your browser. Your PDF and any password you enter are never uploaded to any server — everything happens locally on your device.

### Do I need to know the password to use this tool?

Only if the PDF actually requires one to open. Some PDFs are protected against printing or editing without needing a password just to view them — this tool detects and removes that automatically, no password required. If the PDF does require a password to open, you'll need to enter it correctly.

### What happens if I enter the wrong password?

The tool tells you the password was incorrect and doesn't produce a file. There's no workaround built in — this isn't a password-cracking tool, so it can't unlock a file without the correct password when one is required to open it.

### Does unlocking change the content of my PDF?

No. Removing password protection only affects whether a password is required to open the file — the text, images, and formatting stay exactly as they were.

### Is it legal to unlock a PDF?

It's fine for files you have the right to access — ones you protected yourself or that were shared with you along with the password. Removing protection from a document you don't have permission to open isn't something this tool is intended for.
