## JPG vs AVIF — When to Use Each

| Feature | JPG | AVIF |
|---|---|---|
| File size | Larger | Smaller (roughly 50% of JPEG at similar quality) |
| Image quality | Good, but blocky artifacts at high compression | Excellent, especially at low bitrates |
| Transparency | Not supported | Supported |
| HDR / wide color | Not supported | Supported |
| Compatibility | Universal — every device, browser, and editor | ~93% of browsers, growing website adoption |
| Encoding speed | Fast | Slower, especially at high quality |

### Keep JPG When

- Maximum compatibility matters more than file size
- Uploading to software or platforms without AVIF support
- Sending to a printing service or older device

### Convert to AVIF When

- Serving images on your own website to modern browsers
- Page load speed and Core Web Vitals matter
- You want smaller files without a visible quality hit
- Storage space for a large photo library is a concern
