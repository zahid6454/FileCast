## DOCX vs PDF — When to Use Each

| Feature | DOCX | PDF |
|---|---|---|
| Editing | Fully editable in Word, Docs, etc. | View-only by design |
| Layout consistency | Varies by software and fonts | Identical on all devices |
| File size | Generally smaller | Can be larger with embedded fonts |
| Font rendering | Depends on installed fonts | Fonts embedded in file |
| Collaboration | Track changes, comments, co-editing | Limited annotation tools |
| Digital signatures | Limited support | Industry standard |
| Printing | May shift layout across printers | Print-ready, WYSIWYG |

### Keep DOCX When

Use DOCX when you're still working on a document. It's the right format during drafting, editing, and collaboration. If you need track changes, comments, or co-authoring with others in real time, DOCX is purpose-built for that workflow. Keep documents in DOCX while they're alive and evolving.

### Convert to PDF When

Switch to PDF when the document is final. Contracts, invoices, reports, submissions, resumes — anything that needs to look the same on every screen and every printer should be PDF. It's also the safer choice for sharing externally since the recipient can't accidentally (or intentionally) alter the content.
