    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg></span>
      <h3>Keep PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need maximum compatibility with older software or systems</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're working in a design tool that doesn't export WebP</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The image is part of a workflow that requires PNG specifically</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need a format that every image editor can open without issue</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to WebP When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're optimizing images for a website or web app</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want smaller files without losing visible quality</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need transparency in a smaller file than PNG offers</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're preparing images for a platform that accepts WebP</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want to save storage space on images you view on screen</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're sending images where file size matters but quality should stay high</li>
    </ul>
  </div>
