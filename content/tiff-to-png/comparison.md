## TIFF vs PNG — When to Use Each

Both formats are lossless, but they serve very different purposes.

| Feature | TIFF | PNG |
|---|---|---|
| File size | Very large (30 MB+) | Smaller, still lossless |
| Image quality | Maximum — no detail is lost | Maximum — no detail is lost |
| Multiple pages | Yes — one file can hold several pages | No — one image per file |
| Layers | Supports layers for editing | No layer support |
| Transparency | Supported (alpha channel) | Supported |
| Compatibility | Limited — needs special software | Universal — works on every device and platform |
| Best for | Professional editing, archiving, printing | Web, sharing, editing, general-purpose use |

### Keep TIFF When

- You need to edit the image further in professional software
- You're sending files to a print shop or publisher
- The file contains multiple scanned pages in one document
- You're working with layers that need to stay separate

### Convert to PNG When

- You want a lossless file that opens everywhere
- You need to upload images to a website or online platform
- You're running low on storage space but don't want to lose quality
- The person receiving the file doesn't have software that opens TIFF
- Your TIFF has transparency you need to keep intact
