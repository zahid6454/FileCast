## TIFF vs PNG — When to Use Each

Both formats are lossless, but they serve very different purposes.

<table class="icon-table">

<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-target"></use></svg>Image quality</span></td><td data-label="TIFF">Maximum — no detail is lost</td><td data-label="PNG">Maximum — no detail is lost</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-file-plus"></use></svg>Multiple pages</span></td><td data-label="TIFF">Yes — one file can hold several pages</td><td data-label="PNG">No — one image per file</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-sliders"></use></svg>Layers</span></td><td data-label="TIFF">Supports layers for editing</td><td data-label="PNG">No layer support</td></tr>

<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-edit"></use></svg>Best for</span></td><td data-label="TIFF">Professional editing, archiving, printing</td><td data-label="PNG">Web, sharing, editing, general-purpose use</td></tr>

    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg></span>
      <h3>Keep TIFF When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to edit the image further in professional software</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're sending files to a print shop or publisher</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The file contains multiple scanned pages in one document</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're working with layers that need to stay separate</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want a lossless file that opens everywhere</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to upload images to a website or online platform</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're running low on storage space but don't want to lose quality</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The person receiving the file doesn't have software that opens TIFF</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Your TIFF has transparency you need to keep intact</li>
    </ul>
  </div>
