## PNG vs ICO — When to Use Each

<div class="table-scroll">
<table class="icon-table">
<colgroup><col><col><col></colgroup>
<thead><tr><th>Feature</th><th>PNG</th><th>ICO</th></tr></thead>
<tbody>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-file-plus"></use></svg>Multiple sizes in one file</span></td><td data-label="PNG">No — one image per file</td><td data-label="ICO">Yes — several sizes bundled together</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Favicon support</span></td><td data-label="PNG">Requires a <code>&lt;link rel="icon"&gt;</code> pointing to a PNG</td><td data-label="ICO">Native, universally recognized favicon format</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-edit"></use></svg>Editing</span></td><td data-label="PNG">Easy to edit in any image editor</td><td data-label="ICO">Not directly editable — regenerate from a source image instead</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg>General image use</span></td><td data-label="PNG">Universal — photos, graphics, web images</td><td data-label="ICO">Narrow — favicons and Windows icons only</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-maximize"></use></svg>File size</span></td><td data-label="PNG">Smaller, single image</td><td data-label="ICO">Larger — bundles multiple image sizes</td></tr>
</tbody>
</table>
</div>

<div class="panel-grid">
  <div class="panel panel--neutral">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg></span>
      <h3>Keep PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're editing or designing the logo itself</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need a single image for general use, not a favicon</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're using the image somewhere other than a browser tab or Windows icon</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to ICO When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're setting up a favicon for a website</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want one file that works crisply at every size a browser might display it</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're building a desktop application icon for Windows</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>A CMS or site builder specifically asks for a <code>.ico</code> file</li>
    </ul>
  </div>
</div>
