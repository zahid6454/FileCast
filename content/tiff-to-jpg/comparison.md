## TIFF vs JPG — When to Use Each

Both formats have their place. Here's how they stack up side by side.

| Feature | TIFF | JPG |
|---|---|---|
| File size | Very large (30 MB+) | Small (usually under 5 MB) |
| Image quality | Maximum — no detail is lost | Excellent for viewing, slightly reduced from original |
| Multiple pages | Yes — one file can hold several pages | No — one image per file |
| Layers | Supports layers for editing | No layer support |
| Compatibility | Limited — needs special software | Universal — works on every device and platform |
| Best for | Professional editing, archiving, printing | Sharing, web, email, social media |
| Web support | Most browsers can't display TIFF | Every browser displays JPG |

### Keep TIFF When

- You need to edit the image further in professional software
- You're sending files to a print shop or publisher
- You want an archival copy with zero quality loss
- The file contains multiple scanned pages in one document
- You're working with layers that need to stay separate

### Convert to JPG When

- You want to share photos by email or messaging apps
- You need to upload images to a website or social media
- You want to view pictures on your phone or tablet
- You're running low on storage space
- The person receiving the file doesn't have software that opens TIFF
- You need the image to load quickly on a web page
