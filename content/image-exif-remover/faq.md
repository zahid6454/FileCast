## Frequently Asked Questions

### Is it safe to remove metadata from my photos here?

Yes. This tool processes your image entirely in your browser. Your file is never uploaded to any server — everything happens locally on your device, including reading the metadata that gets removed.

### Does this reduce image quality?

No. This tool edits the file's metadata segments directly rather than re-encoding the image, so the compressed image data itself is never touched. The result is pixel-for-pixel identical to the original — only the hidden metadata is gone.

### What exactly does it remove?

EXIF data (camera model, GPS coordinates, date/time, camera settings), IPTC data (author and caption fields sometimes embedded by editing software), and XMP metadata. The image's color profile is preserved, so colors won't shift.

### Will this change my file size?

Only slightly, and only downward — removing metadata makes the file a little smaller since there's less data in it overall. The visible image dimensions and quality are unaffected.

### Which image formats are supported?

This tool accepts JPG, PNG, and WebP files. The output keeps the same format as your original.
