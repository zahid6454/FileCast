## JPG vs PDF — When to Convert

JPGs and PDFs serve different purposes. A folder of JPG photos is great for viewing and editing individually, but a PDF keeps everything together as a single document. Here is how they compare.

| Feature | JPG Photos | PDF Document |
|---|---|---|
| File count | One file per photo | Single file for all pages |
| Sharing | Must send multiple files or a zip | One file to email or upload |
| Page order | Depends on file naming | Fixed page order |
| Print quality | Varies by viewer | Consistent across devices |
| Editing | Easy to crop, resize, adjust | Requires a PDF editor |

### Keep as JPG When

- You need to edit individual photos — crop, resize, or adjust colors
- The photos will be used on a website, in a presentation, or in a design project
- You want to view and browse photos individually in a gallery
- The images are meant for social media or messaging apps
- You only have one or two photos that don't need to be combined

### Convert to PDF When

- You need to send multiple photos as one organized document
- The photos represent pages of a scanned document, receipt, or form
- You want to preserve a specific page order for the recipient
- A website, portal, or application requires PDF uploads
- You want the photos to print consistently on any device
