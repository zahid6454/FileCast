## Cropping a PDF vs Resizing or Re-Exporting

Trimming margins from a PDF can be done a few different ways depending on what's actually available to you.

| Consideration | This Tool | Re-Export from Source | Print-to-Fit |
|---|---|---|---|
| Works when you only have the PDF | Yes | No — requires the original file | Yes, but only affects the printed copy |
| Changes the file itself | Yes, permanently | Yes, permanently | No — the PDF file is unchanged |
| Precision over the trimmed amount | Yes, exact margin in points | Depends on the software | Limited, driver-dependent |
| Speed | Seconds | Requires reopening and re-exporting | Set per print job, not saved |

### Use This Tool When

- You only have the final PDF, not the original source document
- You want the trimmed margins to be part of the file itself, not just how it prints
- You need a consistent, exact margin removed from every page

### Consider a Different Approach When

- You still have the original source file and can adjust its page size or margins directly before exporting
- You only need the tighter margins for one specific print job — a "fit to page" or "shrink to fit" print setting may be enough without altering the file
