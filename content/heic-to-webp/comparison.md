## HEIC vs WebP — When to Use Each

| Feature | HEIC | WebP |
|---|---|---|
| File size | Very small | Very small |
| Image quality | Excellent at low file sizes | Excellent at low file sizes |
| Transparency | Supported | Supported |
| Animation | Supported (like Live Photos) | Supported |
| Compatibility | Apple devices only | All modern browsers and most apps |
| Web support | Not supported by browsers | Fully supported |
| Editing support | Limited (few editors support it) | Widely supported |

### Keep HEIC When

- Storing photos on your iPhone or iPad
- Saving space on Apple devices
- Working within the Apple ecosystem (AirDrop, iCloud, Mac)
- You need Live Photo or depth map data

### Convert to WebP When

- Publishing images on a website for faster page loads
- You need small files that also work outside the Apple ecosystem
- Uploading to platforms or CMS tools that expect standard web image formats
- You want to keep transparency without JPG's larger file size
