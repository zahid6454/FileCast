## What Is HEIC?

HEIC (High Efficiency Image Container) is the default photo format on iPhones and iPads since iOS 11. It uses the HEIF (High Efficiency Image Format) standard, which delivers the same visual quality as JPG at roughly half the file size.

Apple adopted HEIC because it saves significant storage space on devices. The format also supports features like Live Photos, depth maps, and transparency.

### Why Convert to WebP?

HEIC's efficiency doesn't help outside the Apple ecosystem — most browsers, websites, and image tools don't support it at all. WebP was built by Google for exactly the same goal (small files, high quality) but with support baked into every modern browser. Converting to WebP keeps file sizes close to the HEIC original while making the image usable on the web.
