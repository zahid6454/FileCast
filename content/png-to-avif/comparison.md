      <h3>Keep PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need guaranteed pixel-perfect, lossless output</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Uploading to software or platforms without AVIF support</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Working with graphics, icons, or screenshots where exact reproduction matters most</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to AVIF When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Serving images with transparency on your own website</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Page load speed and Core Web Vitals matter</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>A PNG's file size is much larger than the image content justifies</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Storage space for a large image library is a concern</li>
    </ul>
