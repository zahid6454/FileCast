## Auto-Increment IDs vs. UUIDs

<div class="table-scroll">
<table class="icon-table">
<colgroup><col><col><col></colgroup>
<thead><tr><th>Feature</th><th>Auto-Increment Integer</th><th>UUID v4</th></tr></thead>
<tbody>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-shield"></use></svg>Uniqueness guarantee</span></td><td data-label="Auto-Increment Integer">Only within one database/table</td><td data-label="UUID v4">Effectively global</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-upload-cloud"></use></svg>Generated by multiple systems independently</span></td><td data-label="Auto-Increment Integer">Collides immediately</td><td data-label="UUID v4">Safe</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-search"></use></svg>Predictable/guessable</span></td><td data-label="Auto-Increment Integer">Yes (1, 2, 3, ...)</td><td data-label="UUID v4">No</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-x"></use></svg>Reveals record count</span></td><td data-label="Auto-Increment Integer">Yes</td><td data-label="UUID v4">No</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-maximize"></use></svg>Storage size</span></td><td data-label="Auto-Increment Integer">Small (4-8 bytes)</td><td data-label="UUID v4">Larger (16 bytes / 36-character string)</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-user"></use></svg>Human-typable</span></td><td data-label="Auto-Increment Integer">Easy</td><td data-label="UUID v4">Awkward</td></tr>
</tbody>
</table>
</div>

<div class="panel-grid">
  <div class="panel panel--neutral">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-sliders"></use></svg></span>
      <h3>Use Auto-Increment IDs When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Everything lives in a single database and you control ID assignment centrally</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Storage size and index performance matter more than unguessability</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want IDs a person can easily read, type, or say out loud</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-shield"></use></svg></span>
      <h3>Use UUIDs When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>IDs need to be generated by multiple services, offline clients, or before a record is even saved to a database</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You don't want an ID to reveal how many records exist or make the next one guessable</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're merging data from multiple sources and need to guarantee no collisions</li>
    </ul>
  </div>
</div>
