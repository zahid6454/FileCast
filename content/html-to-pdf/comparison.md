      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-code"></use></svg></span>
      <h3>Keep HTML When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Use HTML when content is interactive, frequently updated, or meant to be consumed on screens of different sizes.</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Web pages, dashboards, documentation sites, and dynamic reports all benefit from HTML's flexibility.</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>If the content needs to be searchable, responsive, or linked from other pages, HTML is the right format.</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-page"></use></svg></span>
      <h3>Convert to PDF When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Switch to PDF when you need a snapshot — a fixed, printable, shareable version of a web page.</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Invoices generated from HTML templates, documentation pages saved for offline reference, receipts, certificates, and reports meant for printing or archiving all work better as PDFs.</li>
    </ul>
