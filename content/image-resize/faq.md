## Frequently Asked Questions

### Is it safe to resize my images here?

Yes. This tool processes your images entirely in your browser. Your files are never uploaded to any server — everything happens locally on your device. No one else can see or access your images during or after resizing.

### What happens if I only enter one dimension?

If you set only the width, the height adjusts automatically to keep the image's original proportions — and the same works in reverse. This proportional scaling prevents your image from looking stretched or distorted. If you enter both width and height, the image scales to match those exact dimensions.

### Will resizing reduce file size?

Yes, in most cases. When you make an image smaller, the resulting file contains fewer pixels and therefore takes up less space. The reduction depends on how much you scale down — cutting dimensions in half typically produces a file that is roughly one-quarter the original size.

### Can I make an image larger?

You can enter dimensions larger than the original, but the tool can only work with the detail that already exists in the image. Enlarging significantly may result in a softer or slightly blurry appearance because new pixels are interpolated from the existing ones. For best results, avoid scaling up beyond 150% of the original size.

### Can I resize multiple files at once?

This tool resizes one file at a time. Select an image, enter your target dimensions, download the result, then start again with the next file. For compressing multiple images in a single session, the bulk compressor tool is available separately.
