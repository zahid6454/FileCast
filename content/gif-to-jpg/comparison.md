## GIF vs JPG — When to Use Each

GIF and JPG are built for very different purposes. Here's how they compare side by side:

      <h3>Keep GIF When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Your image is an animation and you need it to stay animated</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need a transparent background</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The image is a simple graphic, logo, or icon with very few colors</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're using it in a context that specifically requires GIF format</li>
    </ul>
  </div>

    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to JPG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Your GIF is a photograph or has lots of detail and color</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want a smaller file size without visible quality loss</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need a still image from an animated GIF</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're uploading to a website or platform that prefers JPG</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're adding the image to a document, presentation, or email</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The image doesn't need transparency</li>
    </ul>
