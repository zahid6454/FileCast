## GIF vs JPG — When to Use Each

GIF and JPG are built for very different purposes. Here's how they compare side by side:

| Feature | GIF | JPG |
|---|---|---|
| Animation | Yes — supports looping clips | No — static images only |
| Number of colors | Up to 256 | Millions |
| File size for photos | Large | Small |
| Transparency | Yes — fully transparent areas | No |
| Best for | Animations, simple graphics, icons | Photos, detailed images, web pages |

### Keep GIF When

- Your image is an animation and you need it to stay animated
- You need a transparent background
- The image is a simple graphic, logo, or icon with very few colors
- You're using it in a context that specifically requires GIF format

### Convert to JPG When

- Your GIF is a photograph or has lots of detail and color
- You want a smaller file size without visible quality loss
- You need a still image from an animated GIF
- You're uploading to a website or platform that prefers JPG
- You're adding the image to a document, presentation, or email
- The image doesn't need transparency
