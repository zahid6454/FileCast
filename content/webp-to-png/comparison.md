## WebP vs PNG — When to Use Each

Both WebP and PNG are useful image formats, but they serve different purposes. Here is a quick comparison to help you decide which one fits your situation.

<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-target"></use></svg>Image quality</span></td><td data-label="WebP">Good (some data may be lost)</td><td data-label="PNG">Full quality preserved</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg>Transparency</span></td><td data-label="WebP">Supported</td><td data-label="PNG">Supported</td></tr>
<tr><td class="feature-cell"><span class="feature-cell__inner"><svg aria-hidden="true" focusable="false"><use href="#icon-code"></use></svg>Browser support</span></td><td data-label="WebP">Most modern browsers</td><td data-label="PNG">All browsers</td></tr>

  <div class="panel panel--neutral">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-photo"></use></svg></span>
      <h3>Keep WebP When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You are using images on a website and want faster page loads</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>File size matters more than perfect quality</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The images will only be viewed in a modern web browser</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You are optimizing storage for a large collection of web images</li>
    </ul>
  </div>
  <div class="panel panel--accent">
    <div class="panel__head">
      <span class="panel__icon"><svg aria-hidden="true" focusable="false"><use href="#icon-arrow-convert"></use></svg></span>
      <h3>Convert to PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to edit the image in design or photo editing software</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want to share the image and make sure anyone can open it</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need to preserve every detail at full quality</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The image has transparency that you want to keep intact</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You are saving images for long-term archiving</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The app or platform you are using does not accept WebP files</li>
    </ul>
  </div>
