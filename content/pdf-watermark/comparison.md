## Watermarking vs Other Ways to Label a PDF

Marking a document as a draft, sample, or confidential can be done a few different ways. Here's how a stamped watermark compares.

<div class="table-scroll" markdown="1">

| Consideration | Watermark | Header/Footer Text | Password Protection |
|---|---|---|---|
| Visible on every page | Yes, prominently | Yes, but easy to overlook | Doesn't apply — controls opening, not labeling |
| Survives printing | Yes | Yes | Not applicable once opened |
| Deters casual redistribution | Yes, visibly | Weakly | Yes, strongly |
| Blocks opening the file | No | No | Yes |
| Easy to add without the source file | Yes, works on any PDF | Requires the original document | Yes, works on any PDF |

</div>
