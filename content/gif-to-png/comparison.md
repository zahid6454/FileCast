## GIF vs PNG — When to Use Each

GIF and PNG both support transparency, but they're built for different jobs. Here's how they compare side by side:

      <h3>Convert to PNG When</h3>
    </div>
    <ul>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You need a still image from an animated GIF</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>Your image has curved edges or soft shadows that need smooth transparency</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You want to edit the image further in design software</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>The image doesn't need to stay animated</li>
      <li><svg aria-hidden="true" focusable="false"><use href="#icon-check"></use></svg>You're adding the image to a document, presentation, or design project</li>
    </ul>
