## GIF vs PNG — When to Use Each

GIF and PNG both support transparency, but they're built for different jobs. Here's how they compare side by side:

| Feature | GIF | PNG |
|---|---|---|
| Animation | Yes — supports looping clips | No — static images only |
| Number of colors | Up to 256 | Millions |
| Transparency | Yes — fully transparent pixels only | Yes — smooth, partial transparency too |
| File size for photos | Large, with visible banding | Larger, but lossless |
| Best for | Animations, simple graphics, icons | Logos, icons, screenshots, detailed graphics |

### Keep GIF When

- Your image is an animation and you need it to stay animated
- The image is a simple graphic, logo, or icon with very few colors
- You're using it in a context that specifically requires GIF format

### Convert to PNG When

- You need a still image from an animated GIF
- Your image has curved edges or soft shadows that need smooth transparency
- You want to edit the image further in design software
- The image doesn't need to stay animated
- You're adding the image to a document, presentation, or design project
