## PDF vs XLSX — When to Convert

| Feature | PDF | XLSX |
|---|---|---|
| Editing | View-only by design | Fully editable cells |
| Calculations | None — numbers are static | Formulas, sums, sorting, filtering |
| Layout consistency | Identical on all devices | Adjusts to column widths |
| Charts from data | Not possible | Built directly from cells |
| Collaboration | Limited annotations | Shared editing, comments |
| Universal viewing | Any PDF viewer | Needs Excel or compatible app |

### Keep PDF When

Stay with PDF when the document is a finished record — an invoice you've already sent, a statement for your files, a report meant to be read, not recalculated.

### Convert to XLSX When

Switch to XLSX when you need to work with the numbers: rebuilding a budget from a bank statement, combining several invoices into one running total, or sorting and filtering a report someone only sent you as a PDF.
