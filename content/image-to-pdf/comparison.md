## Images vs PDF — When to Convert

Images and PDFs serve different purposes. A folder of photos is great for viewing and editing individually, but a PDF keeps everything together as a single document. Here is how they compare.

| Feature | Individual Images | PDF Document |
|---|---|---|
| File count | One file per image | Single file for all pages |
| Sharing | Must send multiple files or a zip | One file to email or upload |
| Page order | Depends on file naming | Fixed page order |
| Print quality | Varies by viewer | Consistent across devices |
| Editing | Easy to crop, resize, adjust | Requires a PDF editor |

### Keep as Images When

- You need to edit individual photos — crop, resize, or adjust colors
- Images will be used in a presentation, website, or design project
- You want to view and browse photos individually in a gallery
- The images are meant for social media or messaging apps
- You only have one or two pictures that don't need to be combined

### Convert to PDF When

- You need to send multiple images as one organized document
- The images represent pages of a scanned document or form
- You want to preserve a specific page order for the recipient
- A website, portal, or application requires PDF uploads
- You are creating a portfolio, lookbook, or photo collection to share
- You want the images to print consistently on any device
