## Frequently Asked Questions

### Is it safe to convert my text file here?

Yes. This tool processes your file entirely in your browser. Your text is never uploaded to any server — everything happens locally on your device. No one else can see or access your content during or after conversion.

### How does the tool decide where to break lines and pages?

Text is wrapped word by word to fit the page width you choose (Letter or A4), and a new page starts automatically whenever the current one fills up. Blank lines in your original file are preserved as spacing, so paragraph breaks carry over into the PDF.

### Can I change the font size or page size?

Yes. Choose Letter or A4 as the page size, and set a font size between 8pt and 24pt before converting. The default is 11pt on Letter-sized pages, which fits comfortably for most plain-text documents.

### Does this tool support any text formatting?

No — this tool treats the file as plain text, exactly as written, with no bold, italics, or headings. If your file uses Markdown syntax and you want that formatting to render, use [Markdown to PDF](/convert/markdown-to-pdf/) instead.

### Is there a limit on how large a text file I can convert?

Yes, files up to 5 MB are supported — more than enough for even a very long plain-text document, since text itself takes up very little space. The file is processed and paginated entirely in your browser, so very large files may take a moment longer.
