## TXT vs PDF — When to Convert

Plain text and PDF serve different purposes. A `.txt` file is the simplest possible way to store text, but a PDF adds fixed page layout on top of it. Here is how they compare.

| Feature | TXT File | PDF Document |
|---|---|---|
| Layout | Reflows to fit whatever opens it | Fixed page size and line breaks |
| Editing | Trivial in any text editor | Requires a PDF editor |
| File size | Smallest possible | Larger, but still small for plain prose |
| Printing | Depends on the app's own settings | Consistent margins and pagination |
| Formatting | None — plain characters only | Adds structure via pages and margins |

### Keep as TXT When

- You or someone else still needs to edit the content
- The file feeds into another program (a script, a log parser, a build tool)
- You want the smallest possible file size
- Formatting and page layout don't matter for how it's used

### Convert to PDF When

- You need the text to look the same on every device and printer
- A form, portal, or application specifically requires a PDF upload
- You're archiving or printing the text as a finished document
- You want fixed page numbers and consistent margins
