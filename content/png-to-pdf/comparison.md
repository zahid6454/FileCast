## PNG vs PDF — When to Convert

PNGs and PDFs serve different purposes. A folder of PNG images is great for viewing and editing individually, but a PDF keeps everything together as a single document. Here is how they compare.

| Feature | PNG Images | PDF Document |
|---|---|---|
| File count | One file per image | Single file for all pages |
| Sharing | Must send multiple files or a zip | One file to email or upload |
| Page order | Depends on file naming | Fixed page order |
| Transparency | Supported | Flattened onto a white page |
| Editing | Easy to crop, resize, adjust | Requires a PDF editor |

### Keep as PNG When

- You need to edit individual images — crop, resize, or adjust them
- The image relies on transparency (a logo, an icon, a diagram overlay)
- You want to view and browse images individually in a gallery
- The images are meant for a website, app, or design project
- You only have one or two images that don't need to be combined

### Convert to PDF When

- You need to send multiple screenshots or graphics as one organized document
- The images represent pages of a scanned document or form
- You want to preserve a specific page order for the recipient
- A website, portal, or application requires PDF uploads
- You want the images to print consistently on any device
